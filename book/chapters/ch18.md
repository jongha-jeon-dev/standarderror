# A SHAP Value Is an Answer to "Compared With What?"

Chapters 16 and 17 dealt with importance and effects averaged over a whole dataset. SHAP values work on one prediction at a time: they split the gap between this prediction and a baseline into one contribution per feature. Their appeal rests on a theorem, and it is usually summarised as *a SHAP value is the unique fair attribution of a prediction to its features.* Practitioners meet that sentence when an explanation is shown to a customer, a clinician or a regulator, and when a feature is reported as "the reason" for a decision. If the word "unique" hides a choice that the analyst made without noticing, then the reason given for a prediction can change when that choice changes, and the person receiving it has no way to know.

This chapter computes Shapley values exactly, with no sampling or approximation, for a five-feature model of the breast-cancer data. It first defines the Shapley value and what the uniqueness theorem does and does not fix. It verifies the computation on two checks with known answers. It then explains the same predictions against four different reference sets and counts how often the leading feature and the signs of attributions change. It returns to the off-data problem of the previous two chapters, which appears here in a second choice, and ends with a procedure for choosing the reference deliberately.

## The Shapley value and what its theorem fixes

Shapley's 1953 result concerns a cooperative game: a set of $p$ players and a *value function* $v$ that assigns a worth $v(S)$ to every *coalition* $S$, every subset of the players. The question is how to share the total $v(\{1,\dots,p\}) - v(\varnothing)$ among the players. The *Shapley value* of player $i$ is its marginal contribution $v(S \cup \{i\}) - v(S)$, averaged over all the orders in which the players could join:

$$
\phi_i = \sum_{S \subseteq \{1,\dots,p\}\setminus\{i\}} \frac{|S|!\,(p-|S|-1)!}{p!}\,\big[v(S\cup\{i\}) - v(S)\big].
$$

Shapley showed that this is the only way of sharing the total that satisfies four properties: *efficiency* (the shares add up to the total), *symmetry* (two players who contribute the same to every coalition get the same share), the *null-player* property (a player who adds nothing to any coalition gets zero) and *additivity* (the shares for the sum of two games are the sums of the shares). Lundberg and Lee brought the result to model explanation in 2017 under the name SHAP, and "the unique fair attribution" has been its selling point since.

The theorem is about a game, and a model is not a game until someone defines what a coalition of features is worth. The usual definition, the *interventional* one, is: fix the coalition's features at this row's values, draw the remaining features from a *background dataset*, and average the model's predictions over the background rows. The empty coalition then has worth equal to the background's mean prediction, called the *base value*, and the full coalition has worth equal to the prediction for this row. Efficiency says the attributions add up to the prediction minus the base value.

The theorem gives a unique answer for a given value function, and the value function depends on the background. The background is the explanation's answer to "compared with what?", and the theorem has nothing to say about it.

## Computing the values exactly

With five features there are only $2^5 = 32$ coalitions, so every term of the formula can be evaluated directly. The code prints the core of the function used in this chapter.

```python
import inspect
from standarderror.ml import reading as rd

# interventional Shapley values by enumerating all 2^p coalitions
src = inspect.getsource(rd.exact_shapley).split("\n")
print("\n".join(src[6:22]))
```

```text
    val = {}
    for k in range(p + 1):
        for S in itertools.combinations(range(p), k):
            Z = background.copy()
            Z[:, list(S)] = x[list(S)]
            val[S] = float(np.mean(f(Z)))
    phi = np.zeros(p)
    for i in range(p):
        for S, v in val.items():
            if i in S:
                continue
            w = (math.factorial(len(S)) * math.factorial(p - len(S) - 1) /
                 math.factorial(p))
            phi[i] += w * (val[tuple(sorted(S + (i,)))] - v)
    return phi, val[()], val[tuple(range(p))]
```

The first loop builds the value function. For each coalition `S` it copies the background, overwrites the coalition's columns with the explained row's values, and stores the mean prediction. The second loop applies the Shapley formula: for each feature and each coalition that excludes it, it adds the weighted marginal contribution. The function returns the attributions, the base value `val[()]` and the prediction `val[tuple(range(p))]`.

Two checks confirm the computation. For a linear model $\hat f(x) = \beta_0 + \sum_j \beta_j x_j$ the interventional Shapley values are known in closed form: each feature's attribution is its coefficient times the row's distance from the background mean, $\beta_j(x_j - \bar x_j)$. And for any model, efficiency requires the values to add up to the prediction minus the background's mean prediction.

```python
print(f"linear model, exact values vs beta*(x - mean): "
      f"max gap {rd.linear_shapley_check():.1e}")
bg = rd.background_study()
print(f"boosted model, 57 tumours x 4 backgrounds: "
      f"max |sum(phi) - (f(x) - E f)| = {bg['efficiency_error']:.1e}")
```

```text
linear model, exact values vs beta*(x - mean): max gap 2.2e-16
boosted model, 57 tumours x 4 backgrounds: max |sum(phi) - (f(x) - E f)| = 7.1e-15
```

Both gaps are at the level of floating-point rounding. The values computed below are therefore the Shapley values themselves, not estimates of them, and any disagreement between them comes from the definition, not from the arithmetic.

## Four backgrounds give four explanations

The model is gradient boosting (scikit-learn's HistGradientBoostingClassifier) on five breast-cancer features: worst radius, worst concave points, worst texture, mean smoothness and worst symmetry. It is fitted on one stratified 70/30 split, and every third test tumour, 57 in all, is explained. Attributions are in *log-odds* of benign, the scale on which the boosted trees' outputs are summed before the logistic function turns the total into a probability. Each tumour is explained against four backgrounds, each defensible:

- **all training tumours**, the default in most tutorials, which explains why this tumour differs from the average tumour;
- **benign tumours only**, which explains why this one is less benign than a typical benign one;
- **malignant tumours only**;
- **a single row of feature means**, a shortcut many implementations offer because one background row makes every coalition cost one prediction.

The figure below shows the four explanations for one tumour.

For each alternative background, the code compares the 57 explanations with those against all training tumours. It reports the base value, the share of tumours whose feature with the largest attribution changes, and the share of individual attributions whose sign flips.


Against benign tumours only, the feature with the largest attribution is a different feature for 58% of the tumours explained, and 15% of all individual attributions change sign. Against malignant tumours the figures are 30% and 16%. Chapter 66 reruns this comparison on five other train-test splits, and there the benign background changed the top feature for 33% to 53% of tumours. The claim that it changes for most tumours therefore belongs to this split; what survives the rerun is that it changes for a large share.

The feature-means background is the most instructive. Its base value, +2.49, is close to the all-rows value of +2.13, so it looks like a harmless approximation. It flips the sign of 19% of attributions, more than either class-specific background. The reason is that a boosted model is far from linear, and the model's prediction *at* the average tumour is not the average of its predictions *over* tumours. With a single background row, every coalition is evaluated with the missing features fixed at one artificial point instead of spread across real tumours, and each marginal contribution is measured relative to that point.

None of these explanations is wrong. Each is the unique fair split of a different difference. A clinician asking why a tumour was flagged probably means "compared with tumours we would not flag", which is closest to the benign background, and not the population average that the default answers. ## Off the data again: interventional and conditional values

There is a second choice hidden in the interventional definition. Filling in the missing features by drawing them from the background *independently* of the features in the coalition builds rows that combine this tumour's worst radius with another tumour's worst concave points. In this data those two features are correlated at 0.79, so many of the rows built are tumours that do not exist. It is the same problem that Chapters 16 and 17 met in permutation importance and partial dependence: the model is asked about combinations it never saw.

The alternative, *conditional* Shapley values, defines a coalition's worth by drawing the missing features from their distribution *given* the coalition's values, which keeps the rows realistic. It changes the answers again, and it has a cost beyond computation. Under the conditional definition a feature the model never uses can receive credit, because knowing its value changes the expected values of the features the model does use. Janzing and colleagues argue that the interventional version is the right one for asking what the *model* does; Sundararajan and Najmi catalogue how the variants disagree. The choice between them is a second "compared with what?" that the uniqueness theorem leaves open.

What the theorem does guarantee is useful: given a model, a value function and a background, the split is unique and adds up. The table below shows how far apart the backgrounds put the starting point. The skill lies in stating the question, and an explanation is only as meaningful as its stated reference.

## Choosing the background deliberately

If the background is a choice, it should be made like one. Three questions decide it.

**Who is asking, and compared with whom?** A patient asking why their tumour was flagged is comparing it with tumours that were not; a regulator asking why the model behaves as it does across a population is comparing with the population. The first calls for a background of unflagged cases, the second for the whole training set. Here the benign background and the all-tumours background disagreed on the leading feature for 58% of tumours.

**Is the background made of real rows?** A single row of feature means is cheap and is not a tumour anyone has; it flipped 19% of signs. A sample of real rows, even a few hundred, costs more and answers a question about real cases.

**Is the background stated?** An explanation without its reference is like an effect size without its baseline. A sentence of the form "this feature added so much to the log-odds, relative to the average benign tumour" can be checked and argued with; "this feature was the most important" cannot.

A useful habit is to show two backgrounds side by side whenever an explanation matters. Where they agree, the explanation is robust to the choice. Where they disagree, as for more than half the tumours here, the disagreement is itself the honest answer. All of this holds one fitted model fixed; Chapter 19 asks whether a model's accuracy alone can tell us that what it relies on is the task at all.

## In practice

- **Name the background in every explanation.** Write "compared with the average benign tumour, this one's concavity added …", not "concavity was the most important feature".
- **Choose the background from the question.** Use the cases the person asking regards as normal: unflagged cases for an individual who was flagged, the whole population for a question about the model's behaviour overall.
- **Prefer a sample of real rows to a single row of means.** The means shortcut has a base value close to the default and can still flip many signs.
- **Show two backgrounds when an explanation matters.** Report agreement in the top features as evidence of robustness, and disagreement as part of the answer.
- **State the scale and the definition.** Say whether attributions are in log-odds or probability, and whether they are interventional or conditional.
- **Do not infer individual explanations from global bar charts.** A stable ranking of mean absolute values says nothing about any one prediction.

## Limits of the evidence

- **Five features is a toy for enumeration.** Exact computation costs $2^p$ model evaluations per background row. Practical explainers sample coalitions or exploit the structure of trees; their answers approximate the same quantities and inherit the same dependence on the background.
- **Log-odds, not probabilities.** Attributions computed on predicted probabilities are different numbers from those computed on log-odds, and libraries differ in which they report. Everything here is in log-odds. The dependence on the background is part of the definition on either scale, but its size was measured on this one only.
- **One model, one split.** A different model fitted to the same data could rank the features differently for the same tumour even with the background fixed. That was not measured here; Chapter 20 shows that models of near-equal accuracy can disagree on the predictions themselves, which is a reason to expect it. Chapter 66's rerun on other splits narrowed the benign background's effect on the top feature to between 33% and 53% of tumours.
- **Global summaries average the problem away.** Mean absolute Shapley values, the usual "SHAP importance" bar chart, rank the five features in the same order under all four backgrounds, while their sizes move by up to 49% and the leading feature of individual explanations changes for up to 58% of tumours. That stability of the ranking is real and says nothing about any one prediction.

## Key points

1. Shapley values are the unique fair split of the difference between a prediction and a reference. The reference is a choice, and the theorem does not make it.
2. Computed exactly, the values added up to within 7e-15, and switching the background from all tumours to benign ones changed the top feature for 58% of tumours on this split (33% to 53% on five others).
3. The feature-means shortcut kept the base value almost unchanged and still flipped 19% of attribution signs.
4. Interventional and conditional definitions answer different questions; with correlated features they disagree too.
5. State the background in every explanation you show.
